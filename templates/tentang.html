Tentang BurnScan

Teknologi di balik analisis foto.

Kenali cara kerja sistem klasifikasi gambar menggunakan CNN dalam bahasa yang sederhana.

MENGENAL APLIKASI

Apa itu BurnScan?

BurnScan merupakan prototipe website penelitian yang menggunakan pengolahan citra digital dan kecerdasan buatan untuk mengelompokkan gambar berdasarkan dataset.

Sistem ini menggunakan algoritma Convolutional Neural Network (CNN) untuk mengenali pola visual pada gambar.

Selain hasil prediksi, aplikasi menampilkan edukasi pertolongan pertama.

TEKNOLOGI UTAMA

Dua tahap, satu sistem.

Proses analisis dilakukan melalui dua tahap utama.

01 / IMAGE PROCESSING
IMG

Praproses Citra

Sebelum dianalisis, gambar disiapkan agar sesuai dengan masukan yang dibutuhkan model.

Ukuran Gambar disesuaikan ke ukuran 224 × 224 piksel.
Normalisasi Nilai piksel diubah dari 0–255 menjadi 0–1.
Format Gambar dibaca dalam format warna RGB.
02 / DEEP LEARNING
CNN

Convolutional Neural Network

CNN adalah model kecerdasan buatan yang mempelajari pola visual dari gambar. Aplikasi ini memakai arsitektur MobileNetV2 yang dilatih ulang dengan dataset penelitian (transfer learning).

Setelah menerima gambar, CNN menghasilkan skor prediksi untuk kategori yang dipelajari.

Prediksi merupakan hasil pengenalan pola, bukan pemeriksaan medis.

DATASET PENELITIAN

Empat kategori gambar.

Model menggunakan empat label dalam dataset penelitian.

N

Normal

Gambar yang diberi label kulit normal pada dataset.

01

Level 1

Gambar dengan label luka bakar tingkat satu.

02

Level 2

Gambar dengan label luka bakar tingkat dua.

03

Level 3

Gambar dengan label luka bakar tingkat tiga.

Perlu diketahui: Label dataset tidak berarti model mampu memastikan kedalaman luka secara klinis. Luka bakar dapat memiliki kedalaman campuran dan membutuhkan pemeriksaan langsung.
